# AMD-Ghirardelli-Michele

PageRank implemented from scratch on the comments dataset of the New York Times Articles & Comments (2020), for the course Algorithms for Massive Datasets (Master in Computer Science, University of Milan, a.y. 2025/26).

Contents:
- AMD_Michele_Ghirardelli.ipynb — the notebook, runnable on Google Colab
- report.pdf — the report

### Running the notebook

The dataset is downloaded at runtime through the Kaggle API: set your own credentials in the KAGGLE_USERNAME and KAGGLE_KEY variables before running.

By default FULL_DATASET = False, which restricts the analysis to a single month in order to keep the execution time reasonable. The outputs stored in the notebook come from a run on the whole 2020 dataset.
